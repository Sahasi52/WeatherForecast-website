# 🌦️ Weather-Forecast-web

A simple and responsive weather web app built with **HTML**, **CSS**, and **JavaScript**, powered by the **OpenWeatherMap API** to display real-time weather information for any city in the world.

![Logo](./logo.png)

---

## 🚀 Features

- **Search weather by city name (worldwide)**
- **Displays temperature, weather condition, humidity, and wind speed**
- **Dynamic weather icons and styling**
- **Responsive layout for mobile and desktop**
- **Built using only vanilla JS (no frameworks)**
